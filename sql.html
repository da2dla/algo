1. 조회 기본

필요한 열과 행을 고른 뒤 정렬하고 개수를 제한합니다.

SELECT · WHERE · ORDER BY

여러 정렬 기준은 왼쪽부터 적용됩니다.

query.sql
SELECT product_id, product_name, price * 0.9 AS sale_price
FROM products
WHERE category IN ('BOOK', 'OFFICE')
  AND price BETWEEN 10000 AND 50000
  AND product_name LIKE '%SQL%'
ORDER BY sale_price DESC, product_id ASC
LIMIT 10;

DISTINCT · CASE

중복을 제거하고 조건에 따라 값을 분류합니다.

query.sql
SELECT DISTINCT category,
  CASE
    WHEN price >= 50000 THEN '고가'
    WHEN price >= 10000 THEN '일반'
    ELSE '저가'
  END AS price_group
FROM products;

조건식과 NULL

괄호로 AND/OR 우선순위를 분명히 합니다.

query.sql
SELECT * FROM users
WHERE (grade = 'VIP' OR points >= 1000)
  AND deleted_at IS NULL
  AND user_id NOT IN (1, 3, 5);

2. 집계와 그룹

GROUP BY로 행을 그룹화하고 HAVING으로 집계 결과를 거릅니다.

query.sql
SELECT category,
       COUNT(*) AS product_count,
       COUNT(discount_rate) AS discount_count,
       ROUND(AVG(price), 0) AS average_price,
       MAX(price) AS max_price
FROM products
WHERE status = 'ON_SALE'
GROUP BY category
HAVING COUNT(*) >= 3
ORDER BY average_price DESC;
COUNT(*)는 모든 행, COUNT(column)은 NULL이 아닌 값만 셉니다. 집계 결과 조건은 WHERE가 아닌 HAVING에 작성하세요.

3. JOIN

결과에 남겨야 할 기준 테이블을 먼저 결정하고 연결 키를 ON에 씁니다.

INNER JOIN

양쪽에 연결되는 행만 남깁니다.

query.sql
SELECT o.order_id, u.name
FROM orders AS o
JOIN users AS u
  ON u.user_id = o.user_id
WHERE o.status = 'PAID';

LEFT JOIN과 그룹

왼쪽 모든 행을 유지합니다.

query.sql
SELECT u.user_id, COUNT(o.order_id) AS orders
FROM users AS u
LEFT JOIN orders AS o
  ON o.user_id = u.user_id
 AND o.status = 'PAID'
GROUP BY u.user_id;

매칭되지 않은 행 · 셀프 조인

query.sql
-- 주문이 한 번도 없는 사용자
SELECT u.user_id, u.name
FROM users AS u
LEFT JOIN orders AS o ON o.user_id = u.user_id
WHERE o.order_id IS NULL;

-- 직원과 상사 연결
SELECT e.name AS employee, m.name AS manager
FROM employees AS e
LEFT JOIN employees AS m ON m.employee_id = e.manager_id;
LEFT JOIN한 오른쪽 테이블의 필터를 WHERE에 쓰면 NULL 행이 사라질 수 있습니다. 연결 조건이라면 ON에 두세요.

4. 서브쿼리와 CTE

중간 결과에 이름을 붙여 복잡한 쿼리를 단계별로 분리합니다.

EXISTS

query.sql
SELECT u.user_id, u.name
FROM users AS u
WHERE EXISTS (
  SELECT 1 FROM orders AS o
  WHERE o.user_id = u.user_id
    AND o.status = 'PAID'
);

CTE (WITH)

query.sql
WITH totals AS (
  SELECT user_id, SUM(amount) AS total
  FROM orders GROUP BY user_id
)
SELECT user_id, total
FROM totals
WHERE total >= 100000;

5. 윈도우 함수

행을 합치지 않고 그룹 안의 순위·누적값·이전 값을 계산합니다.

그룹별 상위 N개

query.sql
WITH ranked AS (
  SELECT product_id, category, price,
         ROW_NUMBER() OVER (
           PARTITION BY category
           ORDER BY price DESC, product_id
         ) AS rn,
         DENSE_RANK() OVER (
           PARTITION BY category ORDER BY price DESC
         ) AS price_rank
  FROM products
)
SELECT product_id, category, price
FROM ranked WHERE rn <= 3;
ROW_NUMBER는 고유 순번, RANK는 공동 순위 뒤 번호를 건너뛰고, DENSE_RANK는 건너뛰지 않습니다.

누적 합

query.sql
SELECT order_date, amount,
  SUM(amount) OVER (
    ORDER BY order_date, order_id
    ROWS BETWEEN UNBOUNDED PRECEDING
             AND CURRENT ROW
  ) AS running_total
FROM orders;

이전 행

query.sql
SELECT user_id, order_date,
  LAG(order_date) OVER (
    PARTITION BY user_id
    ORDER BY order_date
  ) AS previous_order_date
FROM orders;

6. 문자열·날짜·NULL

함수와 날짜 계산은 DBMS별 차이가 크므로 시험 환경을 먼저 확인하세요.

NULL · 문자열

query.sql
SELECT COALESCE(phone, '없음') AS phone,
       CONCAT(first_name, ' ', last_name) AS name,
       UPPER(category),
       SUBSTRING(phone, 1, 3)
FROM users
WHERE email IS NOT NULL;

날짜 (MySQL 8)

query.sql
SELECT DATE_FORMAT(order_date, '%Y-%m') AS month,
       DATEDIFF(delivered_at, ordered_at) AS days,
       DATE_ADD(order_date, INTERVAL 7 DAY) AS due_date
FROM orders
WHERE order_date >= '2026-01-01'
  AND order_date <  '2027-01-01';
날짜 열을 함수로 감싸기보다 >= 시작일 AND < 다음 시작일의 반열린 구간으로 비교하면 시간값까지 안전합니다.

7. 집합 연산과 DML

UNION 계열은 위아래 결과의 열 개수와 호환 타입이 같아야 합니다.

UNION · UNION ALL

query.sql
SELECT user_id FROM buyers
UNION ALL
SELECT user_id FROM sellers;

-- UNION은 중복 제거, UNION ALL은 유지

INSERT · UPDATE · DELETE

query.sql
INSERT INTO users (name, grade)
VALUES ('Kim', 'BASIC');

UPDATE users SET grade = 'VIP'
WHERE user_id = 7;

DELETE FROM users WHERE user_id = 7;
